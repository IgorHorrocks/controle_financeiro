Esta configuração não usa Client Secret. O navegador usa autenticação de SPA com PKCE. O único identificador colocado aqui é o Application (client) ID, que não é uma senha.
1. Publicar o HTML
Hospede este arquivo em um endereço HTTPS estável (por exemplo, GitHub Pages, Netlify ou Cloudflare Pages). O endereço final precisa ser cadastrado exatamente no Microsoft Entra.
2. Registrar o aplicativo Microsoft
No Microsoft Entra, crie um registro de aplicativo que aceite contas Microsoft pessoais. Em Authentication, adicione a URL acima como plataforma Single-page application (SPA). Em API permissions, adicione a permissão delegada Files.ReadWrite.AppFolder.
